## ⚔️ Mod Features

### 🔥 Adaptive Nemesis — 动态难度平衡

- 🧠 玩家战力实时评估系统
- 📈 敌人动态属性缩放（血量/伤害/护甲/速度）
- 🌍 世界阶段系统（击杀Boss后全服难度提升）
- 💀 真实伤害转换（破甲机制）
- 👹 Nemesis 记忆系统（敌人会学习你的战斗习惯）
- 🌩️ 入侵事件系统

### 🧙 Legendary Mage — 传奇法师

- ⚡ 全新元素反应系统
- 🔥 8种元素印记 + 8种元素减益效果
- ⚗️ 元素反应组合（融化、超导、感电、超载等）
- 📦 完整 Datapack 扩展支持
- 🎨 基于 Iron's Spells 'n Spellbooks
